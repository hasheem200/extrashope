💾 Backup & Restore

⬇️ Export Backup

Downloads a single JSON file containing every collection in the database (users, products, orders, settings, and more). Store it somewhere safe — it includes sensitive data like SMTP credentials and password hashes.

⬆️ Restore from Backup

⚠️ Restoring replaces the current data in every collection found in the file with what's inside it. This cannot be undone — export a fresh backup first if you want to keep the current data.
