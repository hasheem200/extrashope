ExtraShope — Readme / Documentation

Professional eCommerce Template

Overview

ExtraShope is a complete, ready-to-deploy multi-vendor eCommerce marketplace. It includes a public storefront, buyer accounts, seller dashboards, and a full admin control panel — everything needed to run a digital or physical products marketplace out of the box.

What's Included

  • Public storefront with product listing, search, product details, cart and checkout
  • Buyer accounts — orders, wishlist, reviews, notifications, wallet
  • Seller dashboard — add/manage products, shop settings, orders, withdrawals
  • Admin panel — manage users, products, orders, ads, coupons, banners, payments
  • Page Access Control — restrict which roles (Visitor/Buyer/Seller/Admin) can view each page
  • Built-in wallet, withdrawal requests, and payment proof workflow
  • Notification system for buyers, sellers, and admin
  • Site-wide backup/restore tool (export & import full database)
  • SEO-ready: sitemap.xml and robots.txt generated automatically

Tech Stack

  • Backend: Node.js, Express, MongoDB (Mongoose)
  • Authentication: JWT-based, role protected (visitor / buyer / seller / admin)
  • Frontend: Plain HTML/CSS/JS — no build step required
  • Image storage: Cloudinary / Cloudflare R2 compatible uploads

Getting Started

  • Upload the project files to your hosting (or run npm install locally)
  • Set your MongoDB connection string in the MONGO_URI environment variable
  • Start the server with node server.js (or your host's Node.js app runner)
  • Log in as admin from /admin to configure site settings, payments, and access rules

Support

For setup help, customization, or questions about this template, use the Support option from your dashboard after purchase, or contact the seller directly through your order page.
